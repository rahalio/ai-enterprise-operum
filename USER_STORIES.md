# Operum — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### Head of Shared Services / GBS

- As a GBS leader, I want a readiness score by tower and country, so that I invest where capacity and controls can absorb intelligent operations.
- As a GBS leader, I want all tower automation purchases visible in one portfolio, so that I stop paying twice for overlapping bots and AI services.
- As a GBS leader, I want chargeback views by tower, so that funding follows benefit rather than the loudest VP.

### Tower lead (Finance / Supply Chain / HR)

- As a Finance tower lead, I want to register a use case with target cost-to-serve reduction, so that my buy decision is judged on outcomes not tool logos.
- As a Supply Chain lead, I want dependent IT and Procurement impacts flagged before I sign a services SOW, so that my project does not stall on unowned interfaces.
- As an HR tower lead, I want control mapping required before go-live, so that employee data automations do not create audit findings.

### CIO / IT sourcing

- As a CIO, I want vendor engagements tied to portfolio KPIs, so that renewals without impact surface as exceptions.
- As an IT sourcing lead, I want Director- and VP-level influencers recorded on each buy, so that we engage the real buying network the survey describes — not only the CEO.

### CEO / SVP sponsor

- As a CEO sponsor, I want a rollup of readiness and in-portfolio spend across regions, so that intelligent operations is a governed enterprise program rather than twelve local experiments.

### Portfolio administrator / risk

- As a portfolio administrator, I want out-of-band purchases logged as leakage with a remediation deadline, so that shadow buying has consequences.
- As a risk officer, I want to block go-live when control mapping is missing, so that intelligent ops does not bypass SOX or privacy gates.
- As an administrator, I want to export a demographics-style coverage report (tower × region), so that board materials match how the market actually buys.
